### Project Description
This web application manages campus vehicle parking entries using PHP and MySQL.
- `parking.php`: Allows recording of vehicle entry timestamps linked to specific parking slots.
- `report.php`: Displays an organized report joining the vehicle, parking_slot, and parking_entry tables.
