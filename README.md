### Project Description
This web application manages campus vehicle parking entries using PHP and MySQL.
- `db.php`: Establishes the database connection to the MySQL server using `mysqli_connect()`.
- `parking.php`: Form interface to record vehicle entry timestamps and persist records into `parking_entry`.
- `report.php`: Displays an organized report joining `vehicle`, `parking_slot`, and `parking_entry` tables.
